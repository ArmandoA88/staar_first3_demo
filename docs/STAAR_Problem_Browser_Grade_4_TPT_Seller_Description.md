# STAAR Grade 4 ELAR + Math Problem Browser | Desktop Assessment Builder | TEKS

## Description

STAAR Problem Browser is a desktop assessment-building tool that helps teachers turn released STAAR questions into ready-to-print tests and answer keys in minutes. This Grade 4 edition focuses only on Grade 4 ELAR and Grade 4 Math collections.

These are not new or original problems. The app organizes released STAAR items in one place so teachers can quickly find, sort, filter, and build custom assessments without searching through multiple released PDFs one by one.

This Grade 4 build includes 2 ready-to-use collections with 1,007 released items total:

- Grade 4 ELAR — 679 items
- Grade 4 Math — 328 items

Teachers can filter questions by TEKS, year, difficulty, item type, content, and review status. You can search within the collection, add individual questions, add filtered groups of questions, or use built-in presets such as Hardest Test, Easier Test, Latest Questions Only, Spiral Review, Single-TEKS Mastery, Intervention Set, Reteach Set, Benchmark Lite, Mini Quiz, Warm-Up, and Exit Ticket.

ELAR passage bundles stay linked to their questions, including paired and multi-page passages, so reading selections remain connected to the items that go with them.

Once you build a selection, you can add a custom title and class label, reorder questions, and print both a student packet and a teacher answer key.
